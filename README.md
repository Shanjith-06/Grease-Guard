# GreaseGuard – Grease Trap Cleaning Management System

GreaseGuard is a simple web-based system designed for restaurants and commercial kitchens to manage grease trap cleaning schedules and records.

## Features

- Manage grease trap details
- Record cleaning dates
- Identify overdue cleanings
- Maintain cleaning history
- MySQL database integration
- Simple and user-friendly dashboard

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## How to Run

1. Install **XAMPP**.
2. Copy the project folder to:
   `C:\xampp\htdocs\`
3. Start **Apache** and **MySQL** from XAMPP.
4. Open **phpMyAdmin**.
5. Create/import the database using:
   `database/database.sql`
6. Open the project in your browser:

   `http://localhost/GreaseGuard/`
